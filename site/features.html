Product guide

Small details, connected.

The desktop editor brings essential canvas work into one local-first project space. The roadmap distinguishes available tools from active work.

CanvasSystemsReviewProjects

Canvas control

Draw frames, rectangles, ellipses, lines, and text. Select one or many nodes, drag to move, resize, nudge with keys, align, distribute, and reorder with layer-aware commands.

  • Zoom, pan, grid, rulers, guides, and snapping
  • Right-click context menus for selection actions
  • Keyboard shortcuts and dockable editor panels
  • SVG import/export and scoped PNG output

Design systems

Components and tokens are local document data. The Assets panel accepts OS file drops and tracks linked local files. Raster assets are decoded into the native canvas and Present preview.

More advanced asset editing, full vector rendering, library sync, and a plugin API are tracked as planned work.

Review and prototype

Add anchored comment threads, connect a selected layer to a frame, and open a distraction-free presentation preview. Current review information stays inside the project file.

Networked workspaces, live cursors, permission roles, and real-time conflict handling require the optional collaboration service and remain under active development.

Projects that remain yours

A .classic file saves pages, nodes, component definitions, assets metadata, comments, guides, tokens, and prototype links. Local recovery snapshots help protect unsaved work.
