Verify a release

Each release should publish a version, platform target, cryptographic checksum, and provenance details. Compare the release checksum with the downloaded artifact before opening it.

Only download from the project’s configured release page or repository. Do not treat the placeholder links on this page as a release.

Build from source

Classic Studio is a Rust workspace. Install a current Rust toolchain, clone the repository, then build the desktop application:

cargo build --release --workspace

See the repository README for platform prerequisites and current commands.

Updates

Update behavior will be documented with the first public release. Until then, build a new executable from a reviewed source revision.
